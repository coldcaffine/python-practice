# Python Practice Questions

70 beginner Python programs I solved for college practice, one file per question.
Each file has the problem statement as a comment at the top, followed by the solution.

## Topics covered

- Input/output and arithmetic (q1 to q20)
- if / elif / else and string methods (q21 to q35)
- Loops: for, while, break, continue, pass (q4, q6, q37 to q54)
- Functions (q10, q12, q14, q16)
- Tuples, dictionaries and lists with their built-in methods (q36 to q70)

## How to run

Run any file with `python3 q1.py` (change the number for other questions).
Programs that take input will ask for it in the terminal.
